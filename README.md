# ReL Design Studio

Offline-first Android design studio by ReL TV.

## Project scope
- 120 editable offline templates bundled with the app.
- Full offline editing and local project storage.
- Optional free template packs downloadable when internet is available; downloaded packs remain available offline.
- Professional navy and white interface.
- Export designs as JPG, PNG and PDF.
- Save, reopen and edit projects; share exports; backup and restore project files.

## Template catalog plan
| Category | Quantity |
|---|---:|
| Greeting cards | 25 |
| Infographics | 25 |
| Posters | 20 |
| Invitations | 15 |
| Quotes and motivation | 15 |
| Calendars, schedules, menus, biodata, certificates and other | 20 |
| **Total** | **120** |

Templates are intended to be composed of editable text, shapes, images, colors and decorative elements, not flattened images alone.

## Main editor requirements
- Edit text, font, size and color.
- Change background color or use a personal photo.
- Add gallery photos; move, resize and rotate elements.
- Add shapes, lines, icons and ornaments.
- Preview, save locally, reopen and edit designs.
- Export JPG/PNG/PDF, share output, and backup/import projects.
